1 Introduction

This project reproduces a house price prediction analysis from Kaggle, translating code from R to Python while implementing reproducible research best practices.

Original Source: Predicting House Prices using R

Dataset: House Prices - Advanced Regression Techniques

2 Dataset Overview

  • Training samples: 1,460 houses
  • Test samples: 1,459 houses
  • Features: 79 (43 categorical, 38 numerical)
  • Target: SalePrice (continuous regression)
  • Location: Ames, Iowa
  • Data Quality: ~2% missing values, no duplicates

3 Methodology

3.1 Data Preprocessing

Our preprocessing pipeline follows the original R notebook:

  1. Missing Value Imputation
    • Categorical features: filled with “None”
    • Numerical features: filled with mean values
    • 22 features had missing values
  2. Outlier Detection
    • Removed 5 rows with GrLivArea > 4,000 sq ft
    • Based on visual inspection in original R analysis
  3. Categorical Encoding
    • Label encoding for 43 categorical features
    • Preserves feature relationships for tree models
  4. Feature Transformation
    • Log(x+1) transformation for skewed features
    • Threshold: skewness > 0.75
    • Applied to 64 features total
  5. Train/Validation Split
    • 75/25 split on training data
    • Random seed: 123 (reproducible)
    • Final split: 1,092 train, 364 validation

3.2 Model Selection

Random Forest Regressor - 50 trees (baseline) - Scikit-learn implementation - Parallel processing (n_jobs=-1)

Why Random Forest? - Matches original R notebook - Handles mixed feature types well - Provides feature importance - Good generalization on tabular data

3.3 Model Evaluation

Metrics: - RMSE (Root Mean Squared Error) - MAE (Mean Absolute Error) - R² Score
